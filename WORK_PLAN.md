# Work plan / budget discipline

## Chosen path
First build one reusable local animated sequence, record it, show the recording to Yoske, then expand the same code after visual approval. This is an engineering inference aimed at reducing duplicated work, not a measured guarantee of fewer model credits. Account pricing, model choice, token usage and external service limits are unknown.

| Path | Benefit | Extra work / cost uncertainty | Decision |
|---|---|---|---|
| Full website immediately | Most production functionality | Large rework risk if motion direction is rejected | Delay until the motion proof is reviewed |
| Generative video first | Can illustrate impossible shots quickly | Generation credits, character/text inconsistency; still needs implementation later | Not the default; no paid calls without authorization |
| Local motion prototype + browser recording | Exact Hebrew, stable photos, reusable implementation | Needs capture tools; prototype still requires coding | Preferred first proof |

## Bounded first iteration
1. Inspect originals, reference screenshots and evidence labels once.
2. Prepare one clean hero and real Yoske crop. Preserve his body proportions.
3. Build six key scene states with the live Hebrew text.
4. Connect those states to scroll and to deterministic preview progress.
5. Test desktop/mobile, assets, reverse scrolling and reduced motion.
6. Record a 14–20 second proof if tools support it. No audio needed.
7. Deliver source + MP4 + selected keyframes, then get visual feedback.

Do not create many full-page image generations or build backend/booking functionality in the first iteration. Do not run repeated research against already captured references. If one reference cannot be viewed, record the limitation and use the explicitly proposed substitute motion.

## Full website iteration after approval
Home story, actual tour index/details, groups page, real media/testimonials, South America, FAQ/contact. Honor content gaps. Build/lint and browser checks must be real, not claimed from a generated screenshot.

Original standalone logo; current tour detail text; actual review source links; final biographies/credentials; publication permissions; video footage; intended content of the optional guide.
Use an honest text wordmark if a vector logo is missing. Do not recreate a generated mark and call it the real logo.
