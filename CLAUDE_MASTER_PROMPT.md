Scene C: 0.42–0.58 — The passage

Scene D: 0.58–0.82 — The photographs open
Three real travel-photo cards expand from a compact arrangement into an editorial view. Use the Timed Cards composition principle and the fashion reference's image hierarchy. These parameter values are our proposal, not extracted reference values.
Heading: בואו להכיר את חיפה שלי.

## Technical approach
Inspect an existing repository first. For a standalone prototype use a minimal HTML/CSS/JS structure or an existing project stack; this authorizes the prototype choice without a technology-approval interruption. No need for a heavy app framework just to record one scene.
For the full website follow studio stack conventions. Choose a content-focused static architecture unless real requirements justify an application framework. Document any new production stack choice briefly; do not rewrite an existing project gratuitously.
Use one animation mechanism for the initial proof. GSAP/ScrollTrigger is a candidate if available and suitable; CSS transforms/native scroll are valid. Verify current official documentation and licensing when installing. Three.js only if spatial geometry is genuinely needed. A photograph on a transformed plane is 2.5D; identify it accurately. Avoid duplicating GSAP, Framer Motion, Spline and other engines for the same job.

Responsive images, original hero eagerly loaded, below-fold lazy loading, local font/subset if licensed. Do not repeatedly generate assets that can be reused. No backend, authentication, booking, analytics setup or external integrations during the motion proof.

Acceptable proof: welcoming Yoske with authentic body, clean Haifa composition, readable Hebrew, a continuous spatial transition and clear action. Unacceptable proof: same old image with zoom only, slimming the person, multiple unrelated transitions, rough oversized brush font, photo morphing, fake reviews, unverified reference claims, or an MP4 unrelated to the source site.

Start now with the reusable motion proof. Spend effort on the visual result and continuity, not on lengthy explanations, repeated research or an unnecessary infrastructure build.
